info 1. Introduction

TaxStats AI automatise la production des statistiques fiscales à partir de fichiers Excel, en reproduisant les opérations habituelles : TCD, RECHERCHEV, agrégations par secteur et chiffre d'affaires.

Le traitement se fait via un assistant guidé en 7 étapes, accessible depuis le menu Import.

  • Préparez vos fichiers Excel avant de commencer.
  • Créez un nouveau traitement pour chaque campagne statistique.
  • Suivez les étapes dans l'ordre — certaines étapes suivantes sont bloquées tant que la précédente n'est pas terminée.

login 2. Se connecter

Connexion normale

  1. Ouvrez la page de connexion.
  2. Entrez votre identifiant et votre mot de passe (fournis par l'administrateur).
  3. Cliquez sur Se connecter.

Vous pouvez cocher « Rester connecté pendant 30 jours » pour ne pas retaper votre mot de passe à chaque fois.

Vous avez oublié votre mot de passe ?

Pas de panique — on n'utilise pas l'email. Utilisez le mot de passe de secours :

  1. Sur la page de connexion, cliquez sur Oublié?
  2. Dans le champ Code de secours, tapez le code que l'administrateur vous a donné
    (exemple : CRIC-EXT-2026)
  3. Choisissez un nouveau mot de passe (au moins 8 caractères) et confirmez-le
  4. Cliquez sur Réinitialiser le mot de passe
  5. Retournez à la connexion et connectez-vous avec ce nouveau mot de passe

Vous ne connaissez pas le code de secours ? Demandez-le à l'administrateur ou au support {{ organisation_short }}.

Menu Import — bouton « Nouveau traitement » pour recommencer à zéro.

{% else %}

Consultez les TCD finaux (secteur, sous-secteur, relicataires, CA). Téléchargez les exports Excel ou le rapport PowerPoint. Le traitement est marqué comme terminé.

menu 5. Menus et consultation des résultats

  • dashboardDashboard — Vue d'ensemble : totaux, taux de déclaration, graphiques CFLP/secteur, recettes mensuelles, comparaison avec le traitement précédent.
  • file_uploadImport — Assistant de traitement (wizard) décrit ci-dessus.
  • insightsRésultats — Recherche d'un contribuable par NIU ou raison sociale.
  • reportDéfaillants / Déclarants / Relicataires — Listes filtrées par statut fiscal.
  • descriptionRapports — Exports statistiques globaux (Excel, PDF).
  • notificationsCloche (header) — Notifications de fin de consolidation, comparaison, etc.

description 7. Formats de fichiers attendus

Fichiers sectoriels (étape 2)

Excel (.xlsx, .xls) ou CSV. Colonnes requises : NIU et montant déclaré. Format NIU : P ou M + 12 chiffres + 1 lettre.

Fichier en ligne NHR (étape 4)

Liste des contribuables attendus avec colonne NIU obligatoire.

Table secteurs (étape 5)

NIU, Secteur CIME, Sous-secteur.

Fichiers CA (étape 6)

Colonnes : CA_TAXABLE, CA_EXPORT, CA_EXONERE (+ NIU pour le rattachement).
